### 第三题：智能指针的多线程幻相
**【业务场景】：**
为了不漏发任何内存，你使用智能指针对一个全局订单状态做高并发极速抢单：
```cpp
std::shared_ptr<Order> global_order_ptr = std::make_shared<Order>(); 
```
此时有 **10 个工作线程 (Worker Threads)** 正在同时极速并发执行下述逻辑：
```cpp
void WorkerThread() {
    std::shared_ptr<Order> local_ptr = global_order_ptr; // 【动作A：大量拷贝】
    local_ptr->status = "PAID";                          // 【动作B：修改底层物料】
}
```
与此同时，**主线程 (Main Thread)** 接收到了外部强制信号，极其突然地执行：
```cpp
void MainThread() {
    global_order_ptr = std::make_shared<Order>();        // 【动作C：粗暴重置替换】
}
```

**【面试官连环追问】：**
请针对【动作A】、【动作B】、【动作C】，挨个给出判决结论（安全 / 危险必挂），并详细阐述背后的 C++ 内存安全模型原理以及补救的架构重构方案。
